# 💰 MoneyFolio

## 📱 Investment Portfolio Recommendation System

MoneyFolio is a collaborative investment portfolio recommendation system
that recommends investments based on similar investor behavior,
portfolio analysis, and recommendation algorithms.

## 🎯 Main Features

- Investor profile
- Portfolio analysis
- Similar investor identification
- Collaborative filtering
- Investment recommendations
- Content-based recommendations
- Hybrid recommendations
- Investment search
- Portfolio diversification analysis
- Recommendation evaluation

## 📊 Recommendation Method

The system uses User-User Collaborative Filtering
with Cosine Similarity to identify investors with similar
investment behavior and generate personalized recommendations.

## ⚠️ Disclaimer

This project is an academic demonstration using dummy data.
The recommendations are not financial advice and should not be
used for actual investment decisions.
